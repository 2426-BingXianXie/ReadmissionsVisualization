## Visualization 1: Violin Plots

For this multi category distribution visualization, the x-axis lists seven key patient metrics such as hospital stay length, number of lab procedures, number of medications given, and counts of outpatient, inpatient, and emergency visits. The y-axis represents the numerical values associated with each metric. The chart uses a split violin plot to compare the shape of each metric’s distribution between patients who were readmitted and those who were not. This design highlights differences in skew, spread, and density across the two groups, making it easier to identify which clinical measurements tend to be higher among readmitted patients. A pastel color palette of light blue and lavender was chosen to clearly distinguish readmission status while maintaining a cohesive and visually approachable style.

## Visualization 2: Ridgeline Plot of Hospital Metrics

This ridgeline plot displays the distribution of each hospital related metric, with the x-axis showing the actual values and the y-axis listing the variables stacked vertically. Each curve represents how frequently different values occur within a specific feature, making it easy to compare which metrics are tightly clustered, which are heavily right-skewed, and which have long tails. The interactive hover tooltips reveal the feature name and the exact density at any point on a curve, helping users explore patterns that might be hidden in a simple summary chart. A simple, consistent color scheme keeps the emphasis on the shape of each distribution, allowing viewers to clearly understand how different hospital measures vary across the dataset.

## Visualization 3: Average Procedures During Hospital Stay by Age

For this multi-linear visualization, the X-axis contains time in hospital (Days)
and the Y-axis is the average number of procedures done for each age group for the 
amount of time they stay in the hospital. The chart contains interactive elements 
including a selectable age range legend that will allow users to see each line 
alone as well as a hover tooltip that will show age range, time in hospital, 
and average procedures done of each data point. This designs allow viewers to be 
able to clearly see the differences in each point as will as all its data without 
struggling and seeing which is higher than which. The color pallete chosen for this 
plot is a blue pallete that gradually becomes darker as age ranges increase. This 
helps make the plot visually easy to see and matches the different age group axis 
as a whole since they are the same variable with different values.  

## Visualization 4: Frequency of Diagnosis by Age & Primary Diagnosis

This visualization uses a grouped bar chart to display the relationship between 
the top seven primary diagnoses and patient age groups. The grouped bar format 
allows simultaneous comparison across both diagnoses and age demographics. 
A color gradient from dark violet to yellow represents the ten age groups, creating 
a natural progression that helps viewers track age-related patterns across different 
medical conditions. Key design decisions include filtering to the top seven diagnoses 
to maintain readability, incorporating staggered entry animations for visual engagement, 
and providing interactive tooltips with detailed patient counts. The rotated x-axis 
labels accommodate longer diagnosis names, while subtle gridlines offer reference 
points without cluttering the space. A legend on the right maps colors to age groups. 
This design enables quick identification of the most common diagnoses, how age 
distribution varies across conditions, and which demographics are most affected.

## Visualization 5: Medical Specialty Categories with Readmission Rates

This visualization employs a horizontal bar chart displaying readmission rates 
across medical specialties, sorted from highest to lowest. The horizontal 
orientation accommodates lengthy specialty names without rotation or truncation. 
All bars use a uniform steelblue color, avoiding redundant visual encoding since 
readmission rates are already clearly represented by bar length, this maximizes 
the data-ink ratio by eliminating unnecessary complexity. A key feature is the 
vertical crimson reference line showing the overall average readmission rate, 
which appears after the bar animations and allows viewers to immediately identify 
which specialties perform above or below average. Interactive tooltips provide 
specialty names, precise readmission percentages, and sample sizes (patient counts), 
with the latter being crucial for assessing statistical reliability. Subtle vertical 
gridlines aid value estimation without overwhelming the visual. This design effectively 
highlights specialties facing readmission challenges and facilitates meaningful 
comparisons across medical domains.

## Visualization 6: Parallel Coordinates Readmission
I chose a parallel coordinates plot because it allows me to compare several patient attributes at the same time and see how they relate to readmission. This chart makes it easy to spot differences in patterns between readmitted and non-readmitted patients, especially when many variables are involved. The line structure helps me follow each patient’s values across all attributes, and encoding color by readmission status highlights the separation between the two groups. This design gives me a clear way to examine multivariate relationships that would be hard to see in a simple bar or scatter plot.

## Visualization 7: Readmission Rate Heatmap
I selected a heatmap for this part because it summarizes readmission rates across two categorical variables in a compact and readable format. The color scale lets me quickly identify combinations with higher or lower readmission rates without needing to scan individual numbers. This design is effective when comparing many groups at once, and it helps me see patterns that would be difficult to capture with a regular bar chart. The heatmap makes it easy for me to spot high-risk areas and understand how readmission varies across different clinical categories.


## Visualization 8: Glucose Level Amongst Age Groups

This visualization contains a stacked bar chart with X-axis as age groups in the 
dataset and Y-axis as the counts of each glucose levels. It has a filterable side 
glucose legend that allows users to visualize each set of glucose levels individually. 
This helps create a easier viewing of the counts of each level that enables users to 
make clear analysis based on counts for each age group. To make the chart even more 
readible and user-friendly, a hover tooltip was added that will allow audiences to 
view the exact count of each glucose level in each age group with the entire stacked 
bar chart instead of individual selected tests from the legend. The color of this chart 
was chosen to match the age group line chart for a more cohesive design.
